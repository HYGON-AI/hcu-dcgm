# 1 HCU-DCGM简介

HCU-DCGM是一款专为HCU设计的综合性设备管理工具与服务系统，它立足于数据中心级的高性能计算与人工智能应用场景，旨在为HCU硬件资源提供全生命周期的精细化监控、智能化分析与自动化运维能力。作为HCU生态中的关键基础软件，HCU-DCGM汲取了业界先进的设计理念，在架构上采用轻量级、模块化的Golang语言实现，既保证了高性能与低开销的运行特性，又通过标准化的API接口对外提供服务，使得各类第三方系统能够快速集成并构建定制化的监控界面或管理平台。

HCU-DCGM具备强大的实时数据采集能力，能够持续获取HCU的各项关键运行指标，包括但不限于计算单元利用率、显存占用情况、核心与内存时钟频率、功耗水平、温度状态、PCIe总线带宽及错误统计等。通过这些多维度的数据，运维人员可以准确把握HCU的健康状况与性能表现，及时发现潜在问题。在诊断功能方面，HCU-DCGM内置了层次化的健康检查与压力测试体系，提供从Level 1到Level 4共四个级别的诊断测试：Level 1聚焦于驱动版本、固件信息、设备兼容性等基础软硬件验证；Level 2在Level 1基础上增加了显存带宽测试；Level 3进一步纳入PCIe带宽、XHCL互联带宽及GEMM计算性能测试；最高级别的Level 4则包含显存完整性测试与HCU稳定性压力测试，全面评估硬件在极端负载下的可靠性。用户可以通过其命令行工具dcgmi便捷地执行单项或组合测试，并能针对单个设备或设备组进行操作，极大提升了运维效率。

在设备管理层面，HCU-DCGM支持灵活的物理设备分组机制，允许用户根据业务需求将多块HCU卡划分为逻辑组进行统一策略配置与批量操作。同时，系统提供了完善的策略管理功能，管理员可以设定基于温度、功耗、ECC错误计数、PCIe重放错误等阈值的监控策略，并配置超限后的自动化响应动作（如无操作、设备重置等），从而实现从被动告警到主动干预的运维模式转变。其策略监控模式还能让进程持续监听策略违反事件，为关键业务提供不间断的保障。

面向云原生与虚拟化环境，HCU-DCGM提供了先进的虚拟设备（vHCU）管理能力。用户可以在单块物理HCU卡上创建多个虚拟设备，并为每个vHCU独立分配计算单元数量与显存容量，实现硬件资源的细粒度划分与隔离。这一特性使得HCU资源能够更好地适配容器化部署与多租户场景，提升整体资源利用率。配套的完整API支持vHCU的创建、启动、停止、资源动态调整与销毁等全生命周期管理，方便上层平台进行集成。

为了适应不同的部署环境，HCU-DCGM提供了多样化的部署方案。用户可以选择传统的物理机二进制部署，通过简单的环境变量配置即可启动监控服务；也可以采用Docker容器化部署，通过特权模式或普通权限模式在隔离环境中运行，便于持续集成与快速迁移；此外，其命令行工具dcgmi提供了开箱即用的设备信息查看、诊断执行、拓扑分析等功能，满足日常运维与快速排查的需求。对于有深度定制需求的开发者，HCU-DCGM作为Golang库提供了完整的二次开发接口，开发者可以引入其SDK，基于核心功能构建自定义的资源调度算法、监控策略或自动化运维模块，赋能业务系统的深度整合。
